Flight Price Prediction System ✈️📈
A robust machine learning-based application designed to predict flight prices and
provide actionable buying signals. Built with a focus on data accuracy and
seamless user experience by Robo King.
 Features
Predictive Analytics: Uses a machine learning model to estimate future
flight prices.
Smart Signaling: Heuristic-based logic to generate "Buy" signals based on
price trends.
Interactive UI: A clean, responsive dashboard for real-time visualization of
data using Chart.js.
Backend Optimization: Powered by a Python/Flask API with CORS support.
🛠 Tech Stack
Languages: Python, JavaScript, HTML/CSS
Frameworks/Libraries:
Flask (Backend API)
Scikit-Learn (ML Model)
Pandas & NumPy (Data Processing)
Chart.js (Frontend Visualization)
 Installation & Setup
Clone the repository: bash git clone https://github.com/roboking-kourosh-khodayari/flightproject.git cd
flightproject
Install dependencies: bash pip install -r requirements.txt
Run the backend: bash python app.py
Access the interface: Open index.html in your web browser.
